# Abdelrahman Dessouky

Agentic AI and full-stack developer. I build LLM features that run in production (multi-agent workflows, retrieval pipelines, multilingual assistants), plus the interfaces and services around them.

Portfolio: [dessoukyportfolio.vercel.app](https://dessoukyportfolio.vercel.app)

## Selected work

- **[Zabatly](https://github.com/Dessouky13/Zabatly)**: an Arabic/English app that generates interior-design mood boards and room redesigns with Flux, adds LLM-written palettes and furniture lists, and verifies payment screenshots with a vision model. React, Express, PostgreSQL, fal.ai.
- **[HireReady Coach](https://github.com/Dessouky13/Hireready)**: voice mock interviews. The AI interviewer reads your CV, asks questions out loud, follows up on your answers and scores you on six dimensions. React, Supabase Edge Functions, GPT-4o-mini, Whisper, OpenAI TTS.
- **[Siwa with Kelany](https://github.com/Dessouky13/SIWA)**: a multilingual site for a Siwa Oasis tour operator, with WhatsApp booking inquiries and an image pipeline. React, Vite.
